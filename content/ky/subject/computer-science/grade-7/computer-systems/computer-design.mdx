Ар бир санарип түзүлүш — телефон, ноутбук, оюн приставкасы, кир жуучу машина — бир эле дизайнды ээрчийт: **киргизүү** ал, аны **иштет**, **чыгаруу** бер. Бул үлгүнү үйрөн — каалаган түзүлүштүн дизайнын баалай аласың.

<Definition term="Компьютердик система">
  Киргизүүнү алып, аны иштетип, чыгаруу берген жабдуу менен программалык камсыздоонун айкалышы.
</Definition>

## Негизги идеялар

### Киргизүү → Процесс → Чыгаруу

- **Киргизүү** — системага кирген маалымат: клавиатура, чычкан, сенсордук экран, микрофон, камера, сенсорлор.
- **Процесс** — компьютер маалымат менен иштейт: эсептөөлөр, чечимдер, өзгөртүүлөр.
- **Чыгаруу** — жыйынтык системадан чыгат: экран, динамик, принтер, мотор, чырак.

Телефон чалуу: микрофон (киргизүү) → процессор үндү иштетет (процесс) → экинчи учтагы динамик (чыгаруу). Бардык жерде ошол эле үлгү.

- **CPU (процессор)** — көрсөтмөлөрдү аткарат: мээ. CPU канчалык тез болсо, секундасына ошончо көп көрсөтмө.
- **RAM (эстутум)** — CPU азыр колдонуп жатканды кармаган убактылуу жумуш аянты. Электр өчкөндө бошойт.
- **Сактагыч (SSD/диск)** — узак мөөнөттүү сактоо: файлдар, колдонмолор, операциялык система. Өчкөндө да калат.
- **Энелик такта** — баары туташтырылган такта; бөлүктөр ортосунда маалымат ташыйт.

### Дизайнды баалоо

Жакшы дизайн түзүлүштүн жумушуна ылайык. Оюн ноутбугуна тез CPU жана көп RAM керек; фитнес-трекерге кичинекей өлчөм жана батареянын узак иштеши керек, ошондуктан ал жай процессорго макул. Дизайнды баалоо — мындай суроо берүү дегенди билдирет: *ар бир бөлүк бул түзүлүш эмне кылышы керек болгонуна ылайыкпы?*

### Чыныгы колдонуучу үчүн долбоорлоо: майда-чүйдө маанилүү

Дизайнерлер түзүлүштүн функцияларын тандаганда дизайндын бир **аспектисин** карашат — бир бөлүктү же функцияны — жана аны колдонуучунун муктаждыктарына ылайык негиздешет. Текшерүү тизмедеги типтүү функциялар:

Кичинекей экран, жеңил корпус, динамик, микрофон, сенсордук экран, күйгүзүү/өчүрүү баскычы, үндү жөнгө салуу, манжа изи сканери, Bluetooth мүмкүнчүлүгү, катуу сырткы корпус, камера.

Мисал — иштен үйүнө каттаган бош эмес адам үчүн телефон долбоорлоо:

- **Жеңил** — ал аны көп алып жүрөт, ошондуктан өтө оор болбошу керек.
- **Чоң экран** — колдонуучу каттарды жана социалдык тармактарды окуйт, ошондуктан чоң экран бул тажрыйбаны жакшыртат.
- **Сапаттуу динамик** — колдонуучу ызы-чуулуу жерлерде (мисалы, поездде) чалат, ошондуктан ал маектешин жакшы угушу керек.

Ар бир функция колдонуучу чыныгы эмне кылары менен негизделет — практикада дизайнды баалоо дал ушуну билдирет.

<WorkedExample title="Эки дизайнды баала">
  А түзүлүшү: видео монтаждоочу стол компьютери — тез CPU, 32 ГБ RAM, чоң SSD. Б түзүлүшү: электрондук китеп окугуч — жай CPU, 1 ГБ RAM, кичинекей сактагыч, батареянын жумалап иштеши.

  А 4K видео монтаждайт: тез CPU эффекттерди майдалайт, RAM видеокатарды кармайт, сактагыч долбоорлорду сактайт. Б туруктуу текст көрсөтөт: тез CPU батареяны бошко эле түгөтмөк.

  **Жооп:** Экөө тең жакшы долбоорлонгон — анткени дизайн максатына жараша бааланат, таза кубаттуулугуна жараша эмес. Анын кубаттуулугу видеого ылайык; Бнын чектүүлүгү окууга ылайык.
</WorkedExample>

<ImportantNote title="Кеңири таралган каталар">
  - **RAM = сактагыч** Түзөтүү: RAM — убактылуу жумуш аянты (өчкөндө бошойт); сактагыч файлдарды узак сактайт.
  - **Тез — дайыма жакшы** Түзөтүү: дизайн максатына жараша бааланат — трекерге оюн CPUсунун кереги жок.
  - **Программалык камсыздоону унутуу** Түзөтүү: компьютердик система — жабдуу + программалык камсыздоо; программаларсыз бөлүктөр өзүнчө эч нерсе кылбайт.
</ImportantNote>

  </PracticeItem>
  <PracticeItem question="Эмне үчүн ошол эле каттаган адамга сапаттуу динамик да керек болушу мүмкүн? Негизде.">

  </PracticeItem>

<Summary>
  - Компьютердик система: киргизүү → процесс → чыгаруу үлгүсүн ээрчиген жабдуу + программалык камсыздоо.
  - CPU көрсөтмөлөрдү иштетет; RAM — убактылуу жумуш аянты; сактагыч маалыматты узак сактайт; энелик такта баарын бириктирет.
  - Дизайнды максатына жараша баала: жумушка ылайыктуу бөлүктөр, максималдуу кубаттуулук эмес.
  - Сак бол: RAMди сактагыч менен чаташтыруу, «тез — дайыма жакшы» жана программалык камсыздоону унутуу.
</Summary>
