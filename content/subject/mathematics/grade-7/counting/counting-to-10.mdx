Counting is the first big step in mathematics. Every number you learn to say and write opens the door to adding, subtracting and solving problems.

This lesson focuses on Counting to 10: count reliably from 0 to 10 using objects and number songs.

<Definition term="Counting to 10">
  Count reliably from 0 to 10 using objects and number songs.
</Definition>

## Key ideas

### One-to-one counting

Touch or point to each object once and say one number name each time. That way no object is missed and none is counted twice.

### Counting on

Instead of starting at 1 each time, keep counting from a number you already know. This makes adding and checking totals much faster.

**Key term — Estimate:** A sensible guess of how many there are, found by counting part of a group and scaling up.

<WorkedExample title="Worked example: Counting to 10">
  Which is more: 25 or 29?

  29, because 29 comes after 25 when counting.

  **Answer:** 29, because 29 comes after 25 when counting.
</WorkedExample>

<ImportantNote title="Common mistakes">
  - **Counting an object twice** Point to each object once as you count it, moving counted objects aside if it helps.
  - **Saying number names out of order** Practise the sequence aloud until it is automatic, like the words of a song.
</ImportantNote>
