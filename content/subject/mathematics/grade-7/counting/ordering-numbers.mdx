This lesson focuses on Ordering Numbers: place numbers in order from smallest to largest and back.

<Definition term="Ordering Numbers">
  Place numbers in order from smallest to largest and back.
</Definition>

## Key ideas

### Number order

Numbers grow by one each step, so a number further along in the count is always larger: 9 comes after 7 and is bigger.

### One-to-one counting

Touch or point to each object once and say one number name each time. That way no object is missed and none is counted twice.

**Key term — Digit:** Any of the symbols 0 to 9 used to write numbers. The number 42 uses two digits.

<WorkedExample title="Worked example: Ordering Numbers">
  Write the numbers 8, 3, 11, 5 from smallest to largest.

  3, 5, 8, 11.

  **Answer:** 3, 5, 8, 11.
</WorkedExample>

<ImportantNote title="Common mistakes">
  - **Saying number names out of order** Practise the sequence aloud until it is automatic, like the words of a song.
  - **Counting an object twice** Point to each object once as you count it, moving counted objects aside if it helps.
</ImportantNote>
