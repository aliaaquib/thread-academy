## Atoms

Everything around you is built from atoms. Atoms are so small that millions could fit across the width of a human hair. There are about 118 known types of atom. All atoms of the same element have the same number of protons, and this gives the element its identity.

<Definition term="atom">
  The smallest particle of an element that can take part in a chemical reaction.
</Definition>

## Elements and symbols

An element contains only one type of atom. Each element has a symbol of one or two letters. The first letter is always a capital, and the second is lower case. For example, O is oxygen, Fe is iron and Na is sodium. The periodic table lists all the elements.

<Definition term="element">
  A substance made of only one type of atom.
</Definition>

## Compounds

A compound contains atoms of two or more elements chemically bonded together. Water, H₂O, has two hydrogen atoms bonded to one oxygen atom. A compound can have properties that are very different from the elements in it.

<WorkedExample title="Read a chemical formula">
  How many atoms of each element are in one unit of CO₂?

  C has no small number after it, so there is 1 carbon atom.

  The small 2 follows O, so there are 2 oxygen atoms.

  **Answer:** 1 carbon atom and 2 oxygen atoms, which is 3 atoms in total.
</WorkedExample>

<ImportantNote title="Write symbols carefully">
  Co is cobalt, but CO is carbon monoxide. Capital letters change the meaning.
</ImportantNote>

<ExamFocus
  items={[
    { good: "A compound contains two or more elements chemically bonded together.", bad: "A compound is lots of things mixed.", note: "Say chemically bonded, because a mixture is not bonded." },
  ]}
  mistake="Confusing a compound with a mixture. Only the atoms in a compound are chemically bonded."
/>
