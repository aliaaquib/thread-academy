## Learning from examples

Machine learning builds a model that finds patterns in data. In supervised learning, the training data contains examples with correct answers. A spam filter, for example, studies emails labelled spam or not spam. The model adjusts its internal values to reduce its errors, then uses the patterns it learned to make predictions.

<Definition term="feature">
  A measurable input used by a model, such as the number of links in an email.
</Definition>

<Definition term="label">
  The correct output in a training example.
</Definition>

## Training and testing

We split data into a training set and a test set. The model learns from the training set. The test set is kept aside so that we can measure how well the model handles new data. Training accuracy alone can be misleading.

<Definition term="overfitting">
  When a model learns details of the training data so closely that it performs poorly on new data.
</Definition>

<WorkedExample title="Spot overfitting">
  A model scores 99% on training data but only 62% on test data. What does this suggest?

  It works very well on known examples.

  It works much less well on new examples.

  **Answer:** The model has probably overfitted, so it has not generalised well.
</WorkedExample>

<ImportantNote title="Data shapes results">
  A model learns from the data it receives. Biased or unrepresentative data can produce unfair predictions.
</ImportantNote>
