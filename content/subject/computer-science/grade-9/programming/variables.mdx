## Named storage

A variable is a named place in memory that stores a value. You can think of it as a labelled box. Programs use variables to remember scores, names and calculation results. The value can change while the program is running.

<Definition term="variable">
  A named storage location whose value can change while a program runs.
</Definition>

<Definition term="assignment">
  Giving a value to a variable using the = operator.
</Definition>

## Assigning and updating

Python assigns the value on the right to the name on the left. To update a variable, Python works out the right side first, using the current value, and then stores the result.

```python
score = 10
score = score + 5
print(score)
```

This program prints 15.

## Naming rules

Use names that describe the data, such as `total_price`. In Python, names cannot start with a digit or contain spaces, and capital letters matter. `Score` and `score` are different variables.

<WorkedExample title="Calculate a total">
  A shop sells 3 pens at 2 dollars each. Store the values and print the total.

  ```python
  quantity = 3
  price = 2
  total = quantity * price
  print(total)
  ```

  **Answer:** The program prints 6.
</WorkedExample>

<ImportantNote title="Equals means assign">
  In Python, = stores a value. It does not ask whether two values are equal. Use == for that test.
</ImportantNote>
