## Drawing an algorithm

A flowchart shows an algorithm as a diagram. Each shape has a meaning, and arrows show the order of the steps. Programmers often use flowcharts to plan before they write code. This helps them find mistakes early and explain their ideas to other people.

<Definition term="flowchart">
  A diagram that shows the steps of an algorithm using standard symbols.
</Definition>

<Definition term="decision">
  A step with a yes or no question that chooses the next path.
</Definition>

## Standard symbols

| Symbol | Use |
| --- | --- |
| Oval | Start or end |
| Parallelogram | Input or output |
| Rectangle | Process, such as a calculation |
| Diamond | Decision |

<WorkedExample title="Check a password length">
  Plan an algorithm that says whether a password has at least 8 characters.

  1. Oval: Start.
  2. Parallelogram: Input password.
  3. Diamond: Is the length at least 8?
  4. Yes path: Output Strong enough.
  5. No path: Output Too short.
  6. Oval: End.
</WorkedExample>

<ImportantNote title="Every decision needs two paths">
  A diamond must show where to go for yes and where to go for no.
</ImportantNote>
