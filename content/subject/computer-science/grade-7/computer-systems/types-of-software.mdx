Hardware is useless without instructions. **Software** is those instructions — and it comes in two great families: the software that runs the computer, and the software that does your work.

<Definition term="Software">
  Programs and data that tell hardware what to do. The two main types are system software and application software.
</Definition>

## Key ideas

### System software: runs the computer

System software manages the hardware and provides the platform everything else runs on:

- **Operating system (OS)** — the boss: Windows, macOS, Linux, Android, iOS. It controls the CPU, memory, files, and lets you launch programs.
- **Utilities** — maintenance tools: anti-virus software, defragmenting software, data compression software, backup.
- **Drivers** — translators letting the OS talk to hardware like printers.

System software exists to manage and maintain the hardware/computer system — and to allow application software to run. No OS, no apps.

### Application software: does your work

Application software is what you actually open to do things — it exists to allow people to perform everyday tasks with a computer:

- Word-processing software, spreadsheet software, database software
- A web browser, email software, a note-taking app
- A graphics editor, a sound editor, desktop publishing software
- Games

General-purpose, specialist or bespoke — but always: the user's work, not the computer's housekeeping. The three flavours:

- **General-purpose** — everyday tasks for everyone: word processors, spreadsheets, browsers.
- **Specialist** — one profession's job: graphics editors, sound editors, desktop publishing software.
- **Bespoke (custom)** — written for one organisation: a school's timetable system, a supermarket's stock control.

### Why system software has to exist

Humans only need to control certain things on a computer — the things application software lets us control. The rest is handled for us, because:

- Most people would not know how to manage and share out resources like processing power and memory, or how to find and isolate viruses — and doing it by hand would take up a lot of time.
- Some things can be **automated** — done by the computer itself — which is exactly what system software does.
- System processes can run in the **background** at the same time as the user works with application software.

The benefit: humans spend their time and energy only on the things they need and want to do, while the system quietly keeps the machine running beneath them.

### Who makes it, and how you may use it

Software comes with **licences** — permission terms:

- **Proprietary** — owned by a company; you buy or subscribe (Microsoft Office). Source code is secret.
- **Open source** — the code is public; anyone may use, study and modify it (Linux, LibreOffice).
- **Freeware** — free to use, but the code stays closed.

The licence decides what you are *allowed* to do, not just what you *can* do.

<WorkedExample title="Classify the software">
  Four programs: (a) Android, (b) a disk-defragmenter, (c) a photo editor, (d) a hospital's patient-records system written just for it.

  (a) OS → system software. (b) Maintenance tool → system software (utility). (c) Does the user's creative work → application software (specialist). (d) Written for one organisation → application software (bespoke).

  **Answer:** (a) and (b) system software; (c) and (d) application software — classified by job, not by price or fame.
</WorkedExample>

<ImportantNote title="Common mistakes">
  - **"Apps are system software"** Correction: if it does *your* work (write, draw, browse), it is application software — system software runs the computer.
  - **OS = the computer** Correction: the OS is system software; the computer is hardware + software together.
  - **Freeware = open source** Correction: freeware is free to use but closed code; open source publishes the code itself.
</ImportantNote>

## Practice

<PracticeQuestions>
  <PracticeItem question="Is a printer driver system or application software? Why?">
    System software — it lets the OS communicate with hardware; it does not do the user's own work.
  </PracticeItem>
  <PracticeItem question="Give one example each of general-purpose, specialist and bespoke application software.">
    General-purpose: a web browser. Specialist: a music sequencer. Bespoke: a school's own attendance system.
  </PracticeItem>
  <PracticeItem question="Why can application software not run without an operating system?">
    The OS manages the hardware (CPU, memory, files) — apps depend on those services, as the stack diagram shows.
  </PracticeItem>
  <PracticeItem question="What is the difference between open-source and proprietary software?">
    Open source publishes its code for anyone to use and modify; proprietary keeps its code secret and is sold or subscribed under licence.
  </PracticeItem>
</PracticeQuestions>

<Summary>
  - Software: instructions for hardware — system software (OS, utilities, drivers) vs application software.
  - Application software: general-purpose, specialist, or bespoke (custom-built for one organisation).
  - Apps depend on the OS, which depends on the hardware — a stack of layers.
  - Licences: proprietary (owned/secret), open source (public code), freeware (free use, closed code).
</Summary>
