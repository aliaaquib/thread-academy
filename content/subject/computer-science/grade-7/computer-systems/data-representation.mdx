Computers are electrical machines, and electricity is simplest with two states: on or off. So everything — numbers, text, photos, music, programs — is stored as patterns of two digits: **0 and 1**. That is binary.

<Definition term="Binary">
  A base-2 number system using only the digits 0 and 1, matching the two states (on/off) of computer hardware.
</Definition>

## Key ideas

### Why binary? Switches.

A transistor — the tiny switch inside chips — is either on or off. Two states, so two digits. A system with two symbols is called **binary** ("bi" = two), just as our decimal system with ten digits is **denary** ("den" = ten).

### Bits and bytes

- **Bit** — one binary digit: a single 0 or 1. The smallest unit of data.
- **Byte** — 8 bits grouped together, e.g. 01000001. One byte can represent 256 different values (0–255).

Bigger units: kilobyte (KB), megabyte (MB), gigabyte (GB) — each roughly a thousand times the last.

### Binary numbers: place values

Denary place values go 1, 10, 100, 1000 (powers of 10). Binary place values go **1, 2, 4, 8, 16, 32, 64, 128** (powers of 2). Add the values under each 1:

<CodeBlock lang="Example">
  128  64  32  16   8   4   2   1
   0    1    0    1   0   0   1   1
           64 + 16 + 2 + 1 = 83
  So 01010011 in binary = 83 in denary.
</CodeBlock>

To convert denary → binary, subtract the largest place value that fits, working left to right: 83 → 64 fits (1), remainder 19 → 32 no (0) → 16 fits (1), remainder 3 → 8,4 no (0,0) → 2 fits (1), remainder 1 → 1 fits (1): **01010011**.

### The number systems, side by side

- **Denary** — a base-10 number system, mainly used by humans. Ten digits: 0–9.
- **Binary** — a base-2 number system, used by computers. Two digits: 0 and 1.

Try these: 101, 11, 1000, 010, 01, 111 — read as binary, they are 5, 3, 8, 2, 1, 7 in denary. Same digits you already know; completely different values once you know the base.

### Analogue vs digital

The real world is **analogue**: a continuous stream of data made up of many values — sound waves, light shades, temperature gliding up and down. Computers cannot store "continuous", so they convert it to **digital**: binary data a computer system can process. Digitising means sampling the smooth analogue world at many points and storing each measurement as binary.

### Images: pixels, resolution, colour depth

- **Pixel** — a very small part of an image. Millions are laid out in a grid to build the picture.
- **Resolution** — the quality of an image, related to the number of pixels it contains for its size. More pixels, sharper image.
- **Colour depth** — the number of bits used to create colours in an image. With 2 bits per pixel you get 4 colours — for example white, black, red/pink and green.

How an image is digitised, in three steps: the analogue image is divided into pixels; each pixel is given a single colour; each colour has a matching binary value.

### File sizes: why some images are huge

Compare the same photo saved two ways: **tiff** and **raw** files are much larger than **jpg** files — in file size, resolution and bit depth. Why? Tiff and raw are *uncompressed* image types (every pixel stored in full), while jpg is *compressed* (cleverly shrunk). Uncompressed keeps every detail; compressed trades some detail for a far smaller file.

### Sound: sample rate and quality

Digital sound is sampled — measured thousands of times per second. **Higher sample rate = larger file**, because more measurements are stored. And quality needs differ: in voice calls, sound quality is not nearly as important — you just need to understand what is being said. Music is much more complex and exists for entertainment, so quality matters far more there.

<WorkedExample title="Convert 11010110">
  Place values: 128, 64, 32, 16, 8, 4, 2, 1. The 1s sit under 128, 64, 16, 4, 2.

  128 + 64 + 16 + 4 + 2 = 214.

  **Answer:** 11010110 binary = 214 denary. Check: it is under 255, so it fits in one byte — correct.
</WorkedExample>

<ImportantNote title="Common mistakes">
  - **Reading binary left-to-right as tens** Correction: binary place values double right-to-left (1, 2, 4, 8…) — never treat 10 as "ten".
  - **"Binary is only for numbers"** Correction: the same byte can be a number, a letter, part of a pixel or a sound sample — meaning depends on context.
  - **Forgetting leading zeros** Correction: 101 is 00000101 in a full byte — the zeros are part of the value's position.
</ImportantNote>

## Practice

  <PracticeItem question="Convert binary 00101010 to denary.">
    1s under 32, 8, 2 → 32 + 8 + 2 = 42.
  </PracticeItem>
  <PracticeItem question="Convert denary 200 to 8-bit binary.">
    128 fits (1), remainder 72 → 64 fits (1), remainder 8 → 32,16 no (0,0) → 8 fits (1), remainder 0 → 11001000.
  </PracticeItem>
  <PracticeItem question="How is the letter 'B' stored in a computer?">
    As a numeric code (66 in ASCII/Unicode), which is stored as the binary byte 01000010.
  </PracticeItem>
  <PracticeItem question="Why does a photo file contain binary numbers?">
    The image is digitised into pixels; each pixel's colour is stored as binary numbers.
  </PracticeItem>
  <PracticeItem question="What is the difference between denary and binary?">
    Denary is a base-10 number system mainly used by humans; binary is a base-2 system used by computers.
  </PracticeItem>
  <PracticeItem question="What is the difference between analogue and digital data?">
    Analogue is a continuous stream of many values; digital is binary data processed by a computer system.
  </PracticeItem>
  <PracticeItem question="How many colours can 2 bits per pixel represent? Name the four in the book's example.">
    Four colours: white, black, red/pink and green.
  </PracticeItem>
  <PracticeItem question="List the three steps of digitising an image.">
    1. The analogue image is divided into pixels. 2. Each pixel is given a single colour. 3. Each colour is given a matching binary value.
  </PracticeItem>
  <PracticeItem question="Why is a tiff file much larger than a jpg of the same photo?">
    Tiff is uncompressed (every pixel stored in full); jpg is compressed, trading some detail for a smaller file.
  </PracticeItem>
  <PracticeItem question="Why does music need higher sound quality than a voice call?">

  </PracticeItem>

<Summary>
  - Binary: base-2 (0/1), matching hardware's on/off switches; denary is base-10.
  - Bit = one binary digit; byte = 8 bits (0–255). Binary place values are powers of 2.
  - Same binary can represent numbers, characters (ASCII/Unicode codes), images (pixels) and sound (samples).
  - Watch out for: reading binary as tens, thinking binary is numbers-only, and dropping leading zeros.
