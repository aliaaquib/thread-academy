## Checking each item

Linear search looks through a list from the start. It compares each item with the target. If it finds a match, it stops. If it reaches the end without a match, the target is not in the list. The list does not need to be sorted, so linear search works on any data.

<Definition term="linear search">
  A search that checks each item in order until it finds the target or reaches the end.
</Definition>

<Definition term="target">
  The value that a search algorithm is looking for.
</Definition>

## Efficiency

In the best case, the target is first and only 1 comparison is needed. In the worst case, the target is last or missing, so all n items are checked. On average, a search through a list checks about half of the items when the target is present.

<WorkedExample title="Search in Python">
  Write a function that returns the position of a target, or −1 if it is missing.

  ```python
  def linear_search(items, target):
      for i in range(len(items)):
          if items[i] == target:
              return i
      return -1
  ```

  Searching [4, 9, 2] for 2 checks 4, then 9, then 2, and returns position 2.
</WorkedExample>

<ImportantNote title="Return only after the loop">
  Put return -1 after the loop. Inside the loop, it would stop after checking the first item.
</ImportantNote>

<Summary>
  - Linear search checks items in order.
  - It stops when it finds the target.
  - It works on unsorted lists.
  - The worst case checks all n items.
