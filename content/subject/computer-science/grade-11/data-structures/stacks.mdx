## Last in, first out

A stack is a collection where items are added and removed at the same end, called the top. Imagine a pile of plates: you put a new plate on top, and you take the top plate first. This rule is called last in, first out, or LIFO.

<Definition term="stack">
  A last-in, first-out data structure with access only at the top.
</Definition>

<Definition term="LIFO">
  Last in, first out: the newest item is the first to be removed.
</Definition>

## Stack operations

Push adds an item to the top. Pop removes and returns the top item. Peek shows the top item without removing it. Pushing to a full fixed-size stack causes overflow, and popping from an empty stack causes underflow. Programs check for both.

<WorkedExample title="Trace a stack">
  Start with an empty stack. Push 3, push 8, pop, push 5. What is on the stack?

  ```maths
  push 3   → [3]
  push 8   → [3, 8]
  pop      → [3]        returns 8
  push 5   → [3, 5]
  ```

  **Answer:** The stack holds 3 and 5, with 5 on top.
</WorkedExample>

<ImportantNote title="Stacks are all around you">
  Undo features, browser back buttons and function calls all use stacks.
</ImportantNote>

## Practice

<PracticeQuestions>
  <PracticeItem question="Which operation adds an item to a stack?" answer="Push." />
  <PracticeItem question="Which item does pop remove?" answer="The top item, which is the most recently added item." />
  <PracticeItem question="What is stack underflow?" answer="Trying to pop from an empty stack." />
  <PracticeItem question="Explain how a stack can check whether brackets in an expression are balanced." answer="Push each opening bracket. Pop for each closing bracket and check that it matches. The brackets are balanced only if every pop matches and the stack is empty at the end." level="challenge" />
</PracticeQuestions>

<Summary>
  - A stack is last in, first out.
  - Push adds, pop removes and peek looks at the top.
  - Overflow and underflow must be handled.
  - Undo and function calls use stacks.
