Каждое цифровое устройство — телефон, ноутбук, игровая приставка, умные часы — работает на программах. Но не все программы делают одно и то же: одни управляют **самим компьютером**, другие работают **для тебя**.

<Definition term="Программное обеспечение">
  Программы и данные, говорящие компьютеру, что делать; противоположность аппаратуры.
</Definition>

## Ключевые идеи

### Системное ПО: для самого компьютера

**Системное программное обеспечение** управляет аппаратурой и даёт платформу для работы других программ. Главный пример — **операционная система (ОС)**: Windows, macOS, Linux, Android, iOS.

Операционная система делает следующее:
- Управляет аппаратурой (память, время процессора, файлы).
- Даёт платформу для работы программ.
- Предоставляет интерфейс для взаимодействия с пользователем (рабочий стол, сенсорный экран).

Другое системное ПО: драйверы устройств (программы, разговаривающие с принтером), утилиты (резервное копирование, антивирус).

### Прикладное ПО: для тебя

**Прикладное программное обеспечение** выполняет задачу пользователя: текстовый редактор, браузер, игра, таблица, видеоредактор. Работает поверх операционной системы.

### Как их различать

| Системное ПО | Прикладное ПО |
|---|---|
| Управляет компьютером | Выполняет задачу пользователя |
| Напр.: Windows, Android, драйверы | Напр.: Word, Chrome, Minecraft |
| Без него компьютер не загрузится | Без него компьютер работает (но скучно) |

<WorkedExample title="Классифицируй программы">
  Список: Windows 11, Chrome, драйвер принтера, Photoshop, Android, программа резервного копирования.

  Системное ПО: Windows 11 (ОС), драйвер принтера, Android (ОС), программа резервного копирования (утилита).
  Прикладное ПО: Chrome (браузер), Photoshop (редактор изображений).

  **Ответ:** Правило простое — если программа управляет компьютером, это системное ПО; если выполняет твою задачу — прикладное.
</WorkedExample>

<ImportantNote title="Типичные ошибки">
  - **Браузер = операционная система** Исправление: браузер — приложение; работает поверх операционной системы.
  - **Без системного ПО можно обойтись** Исправление: без операционной системы аппаратура сама по себе ничего не делает.
  - **Все программы — приложения** Исправление: драйверы и утилиты — системное ПО.
</ImportantNote>

  </PracticeItem>
  <PracticeItem question="Почему компьютер не может работать без операционной системы?">
    Это слой, управляющий аппаратурой и дающий платформу программам; без него программы не могут говорить с аппаратурой.
  </PracticeItem>
  <PracticeItem question="К какому типу относится антивирус?">

  </PracticeItem>

  </PracticeItem>

<Summary>
  - ПО: программы, говорящие компьютеру, что делать; противоположность аппаратуры.
  - Системное ПО управляет компьютером (ОС, драйверы, утилиты); прикладное ПО выполняет твою задачу.
  - Слои: аппаратура → операционная система → приложения.
  - Остерегайся: считать браузер ОС и думать, что системное ПО не нужно.
</Summary>
