## Вход → машина → выход

**Функция** — это правило, которое превращает каждый вход ровно в один выход. Представьте машину: кладёте 3 — получаете 7. Кладёте 10 — получаете 21. Эта машина удваивает и прибавляет 1.

<Definition term="функция">
  **Функция** — это правило, которое ставит каждому входу в соответствие ровно один выход.
  Мы пишем `f(x) = 2x + 1`, читается как «эф от икс равно 2x + 1».
</Definition>

Запись `f(x)` выглядит как умножение, но это не оно: это *имя* функции (`f`), применённое ко входу (`x`).

## Вычисление значений функции

**Вычислить** `f(3)` — значит подставить 3 везде, где встречается `x`:

```maths
f(x) = 2x + 1
f(3) = 2(3) + 1 = 7
f(−2) = 2(−2) + 1 = −3
f(0) = 1
```

<WorkedExample title="Разобранный пример">
  Если `g(x) = x² − 4`, найдите `g(5)` и значения `x`, при которых `g(x) = 21`.

  ```maths
  g(5) = 25 − 4 = 21
  x² − 4 = 21  →  x² = 25  →  x = 5 или x = −5
  ```
</WorkedExample>

## Обратный путь

Функцию можно обратить, развернув каждый шаг. Если `f(x) = 2x + 1` превращает 3 в 7, то обратная превращает 7 обратно в 3: вычесть 1, затем разделить пополам. Эта обратная функция называется **обратной**, записывается как `f⁻¹(x) = (x − 1)/2`.

Не у каждой функции есть аккуратная обратная — но у каждой линейной есть.

## Функции как графики

Отложите вход по оси x, а выход — по оси y, и функция превратится в **график**. График `f(x) = 2x + 1` — прямая линия; считывать с него значения — то же вычисление, только наглядно. Решить `f(x) = 7` — значит найти, где график достигает высоты 7.

<ImportantNote title="Один вход — один выход">
  Определяющее правило: каждый вход даёт **ровно один** выход. Правило, дающее два выхода для одного входа
  (например, «x = ±√y»), — не функция. На графиках это проверка вертикальной прямой.
</ImportantNote>

## Практика

<PracticeQuestions>
  <PracticeItem question="Если f(x) = 3x − 2, найдите f(4) и f(−1)." hint="Подставьте каждое значение вместо x.">
    `f(4) = 3(4) − 2 = 10`. `f(−1) = 3(−1) − 2 = −5`.
  </PracticeItem>
  <PracticeItem question="Если h(x) = 5 − 2x, найдите x, при котором h(x) = 11." hint="Составьте и решите уравнение.">
    `5 − 2x = 11` → `−2x = 6` → `x = −3`.
  </PracticeItem>
  <PracticeItem question="Запишите функцию, обратную f(x) = 3x + 6." hint="Разверните шаги: что отменяет ×3, а затем +6?">
    Отменяем `+6` (вычитаем 6), затем отменяем `×3` (делим на 3): `f⁻¹(x) = (x − 6)/3`.
  </PracticeItem>
</PracticeQuestions>

<Summary>
  - Функция ставит каждому входу в соответствие ровно один выход; f(x) — это «эф от икс».
  - Вычисляйте, подставляя вход вместо x.
  - Обратные функции разворачивают шаги: сначала отменяйте последнее действие.
  - Графики превращают функции в картинки: решение становится считыванием координат.
</Summary>
