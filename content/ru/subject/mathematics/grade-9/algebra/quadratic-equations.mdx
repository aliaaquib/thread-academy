## Когда x в квадрате

**Квадратное уравнение** содержит `x²` (но не более высокие степени). Его график — кривая, парабола, поэтому у квадратных уравнений может быть **два** решения: кривая может дважды пересечь ось x.

<Definition term="квадратное уравнение">
  **Квадратное уравнение** — это уравнение, в котором наивысшая степень неизвестного равна 2,
  например `x² + 5x + 6 = 0` или `2x² − 8 = 0`.
</Definition>

## Решение разложением на множители

Ключевой приём: **если два сомножителя в произведении дают ноль, то один из них равен нулю.** Итак:

1. Приведите к виду `... = 0`.
2. Разложите квадратный трёхчлен на множители.
3. Приравняйте каждую скобку к нулю и решите.

<WorkedExample title="Разобранный пример">
  Решите `x² + 5x + 6 = 0`.

  ```maths
  x² + 5x + 6 = 0
  (x + 2)(x + 3) = 0      разлагаем: какая пара в сумме даёт 5, а в произведении — 6?
  x + 2 = 0 или x + 3 = 0
  x = −2 или x = −3
  ```

  Проверка при `x = −2`: `4 − 10 + 6 = 0` ✓
</WorkedExample>

Чтобы разложить `x² + bx + c`, найдите два числа, которые в **произведении дают c**, а в **сумме — b**. Для `x² + 5x + 6`: 2 и 3 (2 × 3 = 6, 2 + 3 = 5).

## Формула корней квадратного уравнения

Не каждое квадратное уравнение аккуратно раскладывается на множители. **Формула корней** решает *любое* квадратное уравнение `ax² + bx + c = 0`:

<Formula label="Формула корней квадратного уравнения">
  x = (−b ± √(b² − 4ac)) / 2a
</Formula>

<WorkedExample title="Разобранный пример">
  Решите `2x² + 5x − 3 = 0`, где `a = 2`, `b = 5`, `c = −3`.

  ```maths
  x = (−5 ± √(25 − 4(2)(−3))) / 4
  x = (−5 ± √(25 + 24)) / 4
  x = (−5 ± 7) / 4
  x = 0.5 или x = −3
  ```
</WorkedExample>

<ImportantNote title="Дискриминант">
  Выражение под корнем, `b² − 4ac`, называется **дискриминантом**.
  Если он положителен, решений два; если равен нулю — одно кратное решение; если отрицателен — действительных решений нет.
</ImportantNote>

## Практика

<PracticeQuestions>
  <PracticeItem question="Решите: x² − 9 = 0." hint="Перенесите или разложите как разность квадратов.">
    `x² = 9`, значит `x = 3` или `x = −3`. (Или `(x − 3)(x + 3) = 0`.)
  </PracticeItem>
  <PracticeItem question="Решите x² + 7x + 12 = 0 разложением на множители." hint="Найдите два числа, которые в произведении дают 12, а в сумме — 7.">
    `(x + 3)(x + 4) = 0`, значит `x = −3` или `x = −4`.
  </PracticeItem>
  <PracticeItem question="Решите x² + 4x + 1 = 0 по формуле корней. Ответы дайте с точностью до 2 знаков после запятой." hint="a = 1, b = 4, c = 1.">
    `x = (−4 ± √12)/2 = −2 ± √3`, значит `x ≈ −0.27` или `x ≈ −3.73`.
  </PracticeItem>
</PracticeQuestions>

<Summary>
  - У квадратных уравнений наивысшая степень x² и до двух решений.
  - Чтобы разложить на множители: приведите к = 0, разложите на множители, приравняйте каждую скобку к нулю.
  - Формула корней x = (−b ± √(b² − 4ac)) / 2a решает любое квадратное уравнение.
  - Дискриминант b² − 4ac показывает, сколько существует действительных решений.
</Summary>
